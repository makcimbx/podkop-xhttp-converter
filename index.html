Входная ссылка

Профиль Podkop добавляет XMUX 16–32 только если его нет в ссылке; явные настройки сохраняются. stream-one применяется только к REALITY + auto. Сервер должен поддерживать этот режим.

Поддерживаемая схема: extended 1.13.18-2.6.5 / 1.14.0-2.7.1. Обычный sing-box без XHTTP не подходит. Вставленные данные не отправляются в сеть и не сохраняются сайтом.
